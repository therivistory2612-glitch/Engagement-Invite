# Ritika & Vipul — GitHub Pages

This is a standalone static website. It needs no Cvent, Node.js, npm, or build step.

## Upload without the GitHub size error

1. Download and unzip this package first. Do not upload the ZIP file itself.
2. In your GitHub repository, click **Add file → Upload files**.
3. Upload these items directly into the repository root:
   - `index.html`
   - the complete `assets` folder
   - `.nojekyll`
   - `README.md` (optional)
4. Confirm that `index.html` is visible on the repository's main page, not inside a parent folder.
5. Click **Commit changes**.

## Enable GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/ (root)**.
4. Click **Save** and wait for the published link.

The music file is included as `assets/jab-se-tere-naina.mp3`. Visitors tap the Ganpati opening image to start the invitation and music together.
